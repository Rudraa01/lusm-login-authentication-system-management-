## 1.0.0

* Initial release of `autheasy_flutter`
* `AuthEasyProvider` widget for app-level auth state
* `AuthEasyState` ChangeNotifier with full auth methods
* `AuthEasyClient` for direct API access
* `AuthModal` — drop-in bottom sheet login/signup/OTP UI
* `AuthButton` — pre-built button that shows auth modal
* Secure token storage via `flutter_secure_storage`
* Support for: Login, Signup, OTP Verify, Resend OTP, Forgot Password, Reset Password
* Works on iOS, Android, and Web
